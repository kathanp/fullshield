## Method

Section 48 is not in `SECURITY_SCANNER_SPEC.md`. The file ends at Section 47.5. Categories below are the spec's own phase groups (Sections 12, 24, 25, 29, 32, 37, 39, 42, 46, 47).

A phase is **L0** when no implementation file under `src/`, `scripts/`, `models/`, `templates/`, `.github/`, or `bench/` contains its heading flag or an rule ID the phase introduces (`ID` (severity), `ID`:, or a table cell). A file whose only hit is a sentence that the phase is not implemented is ignored.

**L1** requires that implementation, at least one positive assertion, at least one negative assertion, and, when the phase has a flag, a test that the flag-off path does not add the phase's result. One `it` can carry both assertions. A lane file's "flags are off" test counts as shared flag-off evidence. Phases with no experimental flag treat flag-off as not applicable. Phases 1–16 counts come from the module suites named in Section 12; those files are not phase-isolated.

**L1-gap** means implementation exists and at least one L1 test condition is missing. It is not L0 and it is not L1.

**L2** requires a human-labeled sample under `bench/precision/` with 0 confirmed false positives and n ≥ 20. That directory does not exist. `bench/review/*.csv` has `label`, `reviewer`, and `note` columns and no `tp` / `fp` / `unsure` cells. No phase is L2.

**L3** is the next rung after L2: cross-file taint, type resolution, model packs, or evidence fields where the rule needs them. L2 is unmet, so no phase is L3. The evidence column names a technique when the tree already contains it.

**L4** requires promotion to stable and reviewed holdout recall. `bench/holdouts.json` has `reviewed: false` on every app (nodegoat, juice-shop, dvna, goof, vulnerable-node, verademo-javascript, serverless-goat, mongection). Reviewed apps: none. No phase is L4. Section 30 says nothing has been promoted.

Secret-rule docs: 20 `rules/SECRET-*.md` files, 0 with a `## Rotate` heading, 10 containing the word Rotate.
