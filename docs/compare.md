# FullShield compared with other tools

This page does not add a letter grade, a recall number, or a benchmark.

Default `scan --json` finding keys are the stable contract in [stability.md](stability.md). Reviewed recall for untouched apps is not published. Speed figures, when they are published, come from `bench/perf-v2.json` and are cited in the README. This file does not copy those figures and does not invent new ones.

A comparison that is not measured on a named fixture, on a named commit, with the method written down first, is not a FullShield result.
