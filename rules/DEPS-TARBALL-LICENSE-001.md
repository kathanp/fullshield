# DEPS-TARBALL-LICENSE-001

Direct production dependency only. Both license fields are strings and they differ. A match, or either side missing, is not this finding. This is not `DEPS-LICENSE-001` and it does not judge the license.

## Remediation

Compare the two license strings.
