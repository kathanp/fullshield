# MCP-003

**MCP server exposes shell/exec or unrestricted filesystem-write tools without an allowlist.** CWE-250. Experimental (`FULLSHIELD_EXPERIMENTAL_MCPCFG=1`). Medium.

## Remediation

Restrict filesystem roots to project directories. Do not register shell/exec/write tools unless an allowlist (and a confirm step) is enforced. See `guardTools`.
